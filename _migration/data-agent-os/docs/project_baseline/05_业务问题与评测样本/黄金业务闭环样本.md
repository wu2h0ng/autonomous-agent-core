## Loop 1: 投放效率诊断 (ROI Optimization)

**触发条件**：用户询问 ROI、投放效果、广告效率相关问题
**适用角色**：投放优化师、运营经理
**期望输出**：ROI 现状 → 问题定位 → 行动建议

### Dialog Flow

```
用户：今天的 ROI 怎么样？

Agent：[meta → thought → tool_call → data → insight]
  thought: "需要查询今日 ROI，先确认指标定义和可用数据表"
  tool_call: resolve_metric("ROI")
  data: { metric_name: "ROI", formula: "GMV/AdSpend", ... }
  tool_call: list_tables() → 找到 ads_daily_performance 表
  tool_call: execute_query("SELECT date, SUM(gmv)/NULLIF(SUM(ad_spend),0) as roi FROM ads.daily_performance WHERE date = CURRENT_DATE GROUP BY date")
  data: [{ date: "2026-05-30", roi: 2.35 }]
  insight: "今日 ROI = 2.35，处于正常范围（baseline: 2.0-3.0）。"

用户：和昨天比怎么样？

Agent：
  tool_call: execute_query("SELECT date, SUM(gmv)/NULLIF(SUM(ad_spend),0) as roi FROM ads.daily_performance WHERE date >= CURRENT_DATE - 1 GROUP BY date ORDER BY date")
  data: [{roi_yesterday: 2.68}, {roi_today: 2.35}]
  insight: "ROI 从 2.68 降至 2.35，下降了 12.3%。让我分析原因..."

用户：帮我看看是哪个计划拖后腿

Agent：
  tool_call: execute_query("SELECT plan_id, plan_name, SUM(gmv)/NULLIF(SUM(ad_spend),0) as roi FROM ads.daily_performance WHERE date = CURRENT_DATE GROUP BY plan_id, plan_name ORDER BY roi ASC LIMIT 5")
  data: [{ plan: "计划A", roi: 0.8 }, { plan: "计划B", roi: 1.2 }, ...]
  tool_call: validate_threshold("ROI", "ads.daily_performance", "plan")
  data: { alerts: ["计划A ROI 低于基线 60%", "计划B ROI 低于基线 40%"] }
  insight: "计划A（ROI=0.8）和计划B（ROI=1.2）是主要拖累。建议：暂停计划A，降低计划B出价20%。"

用户：就这么办

Agent：
  insight: "好的，总结一下本次诊断：
  1. 今日 ROI=2.35，较昨日下降 12.3%
  2. 问题计划：计划A(ROI=0.8)、计划B(ROI=1.2)
  3. 优化建议：暂停计划A、降低计划B出价20%、增加计划C预算
  需要我生成详细的优化报告吗？"
```

### 涉及工具
- `resolve_metric` → 确认 ROI 定义
- `list_tables` → 发现可用数据表
- `execute_query` → 查询 ROI 数据
- `validate_threshold` → 异常检测
- `detect_conflicts` → 规则冲突检查（如预算约束）

## Loop 2: 爆款内容挖掘 (Hit Content Discovery)

**触发条件**：用户询问爆款、热门内容、达人表现、内容策略
**适用角色**：内容运营、达人运营
**期望输出**：爆款内容列表 → 特征分析 → 内容策略建议

### Dialog Flow

```
用户：最近有什么爆款内容？

Agent：[meta → thought → tool_call → data → insight]
  thought: "需要查询高互动内容，先了解相关表结构和指标"
  tool_call: search_columns("互动")
  data: [找到 like_count, comment_count, share_count, save_count 等列]
  tool_call: execute_query("SELECT content_id, title, like_count+comment_count+share_count as engagement FROM dwd.content_performance WHERE publish_date >= CURRENT_DATE - 7 ORDER BY engagement DESC LIMIT 10")
  data: [{ content: "夏日穿搭合集", engagement: 52300 }, ...]
  insight: "近 7 天 Top 10 爆款内容如下：第1名「夏日穿搭合集」互动 5.23 万..."

用户：这些爆款有什么共同特点？

Agent：
  thought: "分析爆款内容的标签、发布时间、内容形式等特征"
  tool_call: execute_query("SELECT tag, COUNT(*) as cnt, AVG(engagement) as avg_eng FROM dwd.content_performance WHERE content_id IN (...) GROUP BY tag ORDER BY avg_eng DESC")
  tool_call: execute_query("SELECT publish_hour, AVG(engagement) as avg_eng FROM dwd.content_performance WHERE content_id IN (...) GROUP BY publish_hour ORDER BY avg_eng DESC")
  insight: "共同特征：
  1. 标签集中在「穿搭」「美妆」「测评」
  2. 发布时间集中在 20:00-22:00
  3. 视频形式占比 80%，图文 20%
  4. 平均时长 45 秒
  建议：加大穿搭测评类视频投入，优先在晚 8-10 点发布。"

用户：给我推荐 5 个类似风格的达人

Agent：
  tool_call: execute_query("SELECT creator_id, creator_name, AVG(engagement) as avg_eng, COUNT(*) as content_count FROM dwd.content_performance WHERE tag IN ('穿搭','测评') AND publish_date >= CURRENT_DATE - 30 GROUP BY creator_id, creator_name ORDER BY avg_eng DESC LIMIT 5")
  insight: "推荐达人：..."
```

### 涉及工具
- `search_columns` → 发现内容相关字段
- `describe_table` → 了解表结构
- `execute_query` → 多维聚合查询
- `get_relationships` → 内容→达人关联关系

## Loop 3: 日报全景扫描 (Daily Report)

**触发条件**：用户询问"今日概况"、"日报"、综合指标
**适用角色**：管理者、运营总监
**期望输出**：多指标全景 → 异常标记 → 摘要总结

### Dialog Flow

```
用户：给我今天的数据日报

Agent：[meta → thought → tool_call → data → insight]
  thought: "日报需要覆盖 GMV、ROI、订单量、内容发布、库存预警等多个维度"
  tool_call: list_metrics()
  data: [120+ metrics listed]
  thought: "选取核心指标：GMV、订单量、ROI、转化率、新增内容数、库存告警数"
  tool_call: execute_query("SELECT SUM(gmv) as total_gmv, COUNT(DISTINCT order_id) as orders FROM ads.daily_performance WHERE date = CURRENT_DATE")
  tool_call: execute_query("SELECT SUM(gmv)/NULLIF(SUM(ad_spend),0) as roi, AVG(conversion_rate) as cvr FROM ads.daily_performance WHERE date = CURRENT_DATE")
  tool_call: execute_query("SELECT COUNT(*) FROM dwd.content_performance WHERE publish_date = CURRENT_DATE")
  data: [{ total_gmv: "¥1,250,000", orders: 3200, roi: 2.35, cvr: 3.2%, new_contents: 45 }]
  insight: "📊 今日数据日报 (2026-05-30)
  - GMV: ¥125 万（环比 +5.2% ✓）
  - 订单量: 3,200 单（环比 +3.1% ✓）
  - ROI: 2.35（环比 -12.3% ⚠️）
  - 转化率: 3.2%（正常 ✓）
  - 新增内容: 45 条
  ⚠️ ROI 下降需要关注，建议深入分析投放效率。"

用户：ROI 下降是怎么回事？

Agent：
  → 转入 Loop 1 (投放效率诊断)
```

### 涉及工具
- `list_metrics` → 获取指标体系
- `execute_query` → 多指标并行查询
- `check_data_quality` → 数据质量校验
- `validate_threshold` → 异常标记
