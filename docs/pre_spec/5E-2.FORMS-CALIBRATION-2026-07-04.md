## Claim Tested

The zero-shot branch did not find a freeze-ready region. This pilot tested the
second 5e-2 region: non-enumerable functional forms. The proposer supplies typed
features such as threshold products, saturation products, and ratios; the
existing `InvariantStructureFilter` verifies the supplied features.

This is not an LLM capability claim. The current proposal source is
`manual_data_blind_function_form_proposals_v0`, used only to test whether this
arena can expose a unique form-proposal region. It does not authorize a freeze
verdict, r-final, autonomy claim, product claim, route promotion, or C6/C7
change.

## Readout

The forms branch is healthier than zero-shot in one respect: the typed form
proposals reached the oracle-normalized ceiling in Condition A and collapsed in
Condition B. That means the arena can detect form knowledge.

The branch is not freeze-ready because cheap pair screening still achieved
`median_s_pair_screening=0.7823`. The current arena therefore does not isolate a
unique non-enumerable-form advantage; pair products proxy the true nonlinear
forms too well.

Disposition: do not freeze this gate. The next legitimate move is an arena
redesign that breaks pair-product proxies while keeping the form verifier
healthy, or park 5e-2 and spend the next budget on seam/scale work.
