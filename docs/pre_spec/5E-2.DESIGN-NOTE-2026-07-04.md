# 5e-2 design note — the knowledge channel's UNIQUE region (freeze-ready; run next session)

5e result: data-blind LLM pruning reaches the oracle ceiling where enumeration degrades — but cheap
data-screening reaches it too (MET-weak). 5e-2 tests the two regions screening CANNOT enter:
1. ZERO-SHOT (pre-data): propose the candidate set BEFORE any data exists; verify on later-arriving
   small data (n too small for screening to rank 1,770 pairs but enough to verify 30). Arms: LLM-zeroshot
   vs screening-on-the-same-small-data vs random-k vs oracle. Bar: LLM matches oracle-set verification
   at n where screening's ranking collapses (pilot the collapse point first).
2. NON-ENUMERABLE FORMS: hypothesis space = functional forms (threshold/saturation/ratio interactions),
   not pairwise products — screening has no finite enumeration to rank; the LLM proposes form+variables;
   the verifier tests supplied-form features (typed routing intact: LLM nominates, invariance verifies).
   Condition-B (incongruent names) again the knowledge control.
Protocol self-check pre-answered: referees = oracle-set verification ceilings measured in pilot; bars
relative; leakage rules identical to 5e (prompt = pure schema function, hashes preregistered).
