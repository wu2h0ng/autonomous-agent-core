# 5e-2 design note — the knowledge channel's UNIQUE region (freeze-ready; run next session)

5e result: data-blind LLM pruning reaches the oracle ceiling where enumeration degrades — but cheap
data-screening reaches it too (MET-weak). 5e-2 tests the two regions screening CANNOT enter:
1. ZERO-SHOT (pre-data): propose the candidate set BEFORE any data exists; verify on later-arriving
   small data (n too small for screening to rank 1,770 pairs but enough to verify 30). Arms: LLM-zeroshot
   vs screening-on-the-same-small-data vs random-k vs oracle. Bar: LLM matches oracle-set verification
   at n where screening's ranking collapses (pilot the collapse point first).
2. NON-ENUMERABLE FORMS: hypothesis space = functional forms (threshold/saturation/ratio interactions),
   not pairwise products — screening has no finite enumeration to rank; the LLM proposes form+variables;
   the verifier tests supplied-form features (typed routing intact: LLM nominates, invariance verifies).
   Condition-B (incongruent names) again the knowledge control.
Protocol self-check pre-answered: referees = oracle-set verification ceilings measured in pilot; bars
relative; leakage rules identical to 5e (prompt = pure schema function, hashes preregistered).

## Functional-forms calibration result — 2026-07-04

Artifact: `experiments/cwm_learn_5e2_forms.result.json`.
Record: `docs/pre_spec/5E-2.FORMS-CALIBRATION-2026-07-04.md`.

Result: no freeze-ready non-enumerable-form region was found. The manual
data-blind typed-form proposer was strong in Condition A
(`median_s_proposed_forms=1.0000`) and collapsed correctly in Condition B
(`median_s_proposed_forms=median_s_random_forms=0.6072`), so the form-verifier

unique form-proposal advantage.

Disposition: do not freeze forms by ignoring the pair-screening baseline. The
next legal move is a redesigned forms arena that breaks pair-product proxies
while preserving verifier health, or parking 5e-2 in favor of seam/scale work.

## PILOT (2026-07-04): **zero-shot region EMPTY at this arena — half the design killed pre-freeze**

| n | screening recall@30 | given-30 verified AUC |
|---|---|---|
| 40 | 0.583 | 0.684 |
| 80 | **1.000** | 0.831 |
| 160/320 | 1.000 | 0.913/0.928 |

Screening's ranking and the verifier's soundness collapse TOGETHER (both driven by the same SNR; the
true pairs' marginal product-correlation at beta_xor=1.2 is visible to screening at tiny n). There is
NO n where knowledge-nomination beats data-screening on sample-starvation grounds in this arena.
**5e-2 PRIMARY redirected to the NON-ENUMERABLE FORMS region** (threshold/saturation/ratio functional
forms: screening has no finite candidate list to rank — structurally excluded, not sample-starved).
Sixth pre-freeze catch by the pilot pattern. Next session: forms-arena construction + its own pilot
(form-verification feasibility + form-screening impossibility check) -> freeze.
