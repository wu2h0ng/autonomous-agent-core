- Status: Accepted(2026-06-12 founder 批准 D1 例外:"G1' 带上下文器官重测")
- Founder note: `ContextualActionModel` 例外获批——补缺失器官以公平检验主张2,非救援式调参。
- Date: 2026-06-12
- Deciders: agent(ADR-0003 协议,经 technical-architect 评审)
- Relates: ADR-0002(G1 原环境)、ADR-0004(机制结构修订权已用尽)、ADR-0005(G1 三连未达)、ADR-0007(轨C)

## Context: G1 事后剖检的真因(比 ADR-0005 更深)

读 `cue_shift.py` + `agent.py` 后定位到 recovery 屡败的结构性真因:

1. **动作选择不看线索值**。`policy.select(model, explore, pressure)` 的 `model` 是
   `ActionOutcomeModel`(非上下文 bandit,行动→奖励)。注意力机制估计"哪些线索有信息力(IP)",
   但**线索的取值从不进入选动作**。于是即使完美注意到相关集 S,agent 也无法据此选对动作。
2. **recovery 度量本身坏掉**。`model.best_action() == env.best_action_for(cues)`:左边是一个非上下文的
   单一最优动作,右边是随线索取值而变的最优——在均衡映射下基本只能靠运气(~1/n_actions)匹配。
3. 故 A3(均匀)追平精巧机制**不是因为相关性实现为假**,而是**没人在解上下文结构**:modulated 注意到了
   正确线索却在选动作时把信息丢了。**当前环境无法证实也无法干净证伪主张2**——它测的是一个缺了器官的 agent。

**含义**:光造更难的环境不够。要公平检验"相关性实现",agent 必须先有把"注意到的线索"兑现成
"据此选动作"的上下文通路;否则任何环境都测不出相关性收益。

## Decision

### D1(触碰机制冻结,需 founder 点头):新增上下文动作通路 `ContextualActionModel`

- 机制:`g_hat(被注意线索的取值模式) → 动作价值`。注意力选出 m 个线索 → 该模型按其**取值**学习
  "在这组线索下哪个动作好"。这才让"注意对线索"转化成"选对动作"。
- 仅用于 cue 型环境;`GridlessSurvival` 保留 `ActionOutcomeModel`(向后兼容)。
- **为何这不是"为过门调机制"(诚实声明)**:ADR-0004 用尽的是 `AttentionField` 的结构修订权;这是**补一个
  缺失的、使相关性可被行动兑现的器官**,不是调注意力参数去凑过门。但它**确实改变了主张2的被测机制定义**,
  故按 ADR-0007"机制冻结"例外处理:**列为预注册新组件,founder 明确点头后方可纳入 G1' 重测**。
  founder 若否决,则 G1' 退化为"证明缺器官的 agent 必败"——那应如实记为主张2在当前架构下不可证实。

### D2:区分力环境(再框定决定生死)

新环境(`src/envs/` 新建或 LatentCueForaging 受控参数化,实施者择优,须在本 ADR 记录最终形态):

- **漏判致命**:`reward_miss` 显著加重 + 预算收紧,使"突变后仍按旧 S/g 行动"会快速耗尽预算而死。
- **突变对抗化**:新 regime 的 g 选取为与旧 g 在常见线索模式上**最大冲突**——旧策略突变后**主动变错**,
  不再框定即死。注意:此设计令**所有变体面对同等致命性**,只有真正再框定者存活——是"让再框定有意义",
  **不是**"让我方机制取巧过门"。
- **判据由生存承载**:核心信号从"每步 regret"转为"突变后存活/再框定速度",使相关性实现的价值
  (快速重识别 S 与 g)成为生死变量。

### D3:消融共享上下文骨架(隔离"相关性"为唯一自变量)

**所有变体都装 `ContextualActionModel`**,只在"如何选注意线索"上不同:

| 变体 | 注意力 | 上下文动作 |
|---|---|---|
| B0 modulated | IP 自适应选 m 线索 | 有 |
| B1 fixed | 固定随机 m 线索(永不重选) | 有 |
| B2 full | 全注意 m=K(付 K·α) | 有 |
| B3 uniform | 轮转 m 线索 + 固定探索 | 有 |
| B4 对照(可选) | IP 自适应 | **无**(用旧非上下文 model) |

B4 用于演示"上下文动作通路正是此前缺的器官"(预期 B4≈B3,皆差)。

### D4:修正 recovery 度量为行为再框定

突变后,滑窗 W(默认 20)内 agent 实际所选动作 == `best_action_for(cues)` 的占比 ≥ θ(默认 0.7)时记"已恢复",
recovery_steps = 突变到首个达标窗口的步数。**度量 agent 行为的再框定,不再用坏掉的 `model.best_action()`**。

### 预注册门 G1'(跑前钉死,不得挪)

种子 0–9,每种子 ≥ max(1200, regime_period×20) 步,环境参数取本 ADR 最终形态:

1. **相关性价值**:B0 存活步数 > B1 **且** > B3,各 ≥7/10 种子。
2. **再框定速度**:B0 行为 recovery(D4)快于 B1 **且** B3,各 ≥7/10 种子。
3. **代谢必要性**:B0 存活步数 > B2,≥7/10 种子(选择性注意在致命预算下必要)。
4. **无特判**:跨变体无针对单一消融的特判代码。
5. **诚实证伪条款**:若 B0 在补齐上下文通路 + 致命再框定下**仍**未能在存活与 recovery 上同时打赢 B3,
   则主张2 在"有界注意力 + 上下文动作"这一最有利设定下被更深证伪 → 升级 founder 定主张2 最终状态
   (对主张下结论是 founder 保留权)。

## Consequences

- 机制(`AttentionField`)保持冻结;新增的是上下文动作器官(经 founder 批准)与新环境+新度量,均属可预注册项,非调参。
- `agent.py` 选动作路径变更 = 与轨A 共享接缝,串行(ADR-0007/ADR-0009 纪律):建议轨A ISO-1 先落,轨C 在其上加上下文通路。
- 主张2 当前状态如实保持"部分验证 + 原环境无法证实,待 G1' 重测";G1' 结果(无论正负)写回 RR-0003 与 PROJECT_PLAN §5。
- B4 对照将正式记录"非上下文架构无法兑现注意力"这一事后发现,作为方法论资产。

## G1' 实验结果(2026-06-12)

**G1': NOT MET**(诚实负结果,未为过门调机制)。环境有效性修订一次(首版预算 45 致全员第一次漂移前饿死、零 recovery、无区分力 → 改为 budget=120/metabolic=0.1/capacity=200,reward_miss=-1.5/attention_cost=0.1;随机重映射,**未采用 D2 拟议的对抗重映射,以免向我方机制 rigging**——记为 D2 最终形态)。

均值(种子0-9):B0=211.2 步 / B1=181.9 / B2=61.3 / B3=126.7 / B4=210.9。

| 判据 | 结果 | 需 |
|---|---|---|
| 1 B0 steps > B1 | 5/10 | ≥7 |
| 1 B0 steps > B3 | **8/10 PASS** | ≥7 |
| 2 B0 recovery 快于 B1 | 3/10 | ≥7 |
| 2 B0 recovery 快于 B3 | 3/10 | ≥7 |
| 3 B0 steps > B2 | **10/10 PASS** | ≥7 |

**诊断(经 600 步 instrument 确认,非 bug)**:
- 上下文器官**在工作**:B0 自信利用 45%,自适应注意力稳定到 ~9 个注意集、键均访 16 次——**确实在追踪漂移的 S**。故 B0 干净打赢 B3(均匀 8/10)与 B2(全注意 10/10,B2 因注意力成本 + 全维键碎片化饿死)。
- 未过门两处:(a) B0 vs B1(固定注意)仅 5/10——B1 在其固定集偶然覆盖 S 的 regime 上,稳定键学得快,高方差使其偶尔反超;(b) recovery 判据 3/10,且 recovery 度量**过稀疏**(致命环境多数体活不到 20 步/70% 窗口;#rec:B0=5 B1=2 B3=1)——是弱区分器,方法论教训。
- B4(非上下文)均值存活 ≈ B0,主要是高方差离群点(B4 两个 422/339 离群)所致,per-seed 噪声大;但 B4 未被干净压制本身是警示。

**结论**:主张2 获**部分支持**(器官有效、自适应注意力追踪 S、干净打赢均匀/全注意基线),但**未清预注册门**(输在 vs 固定注意 + recovery 速度)。这是主张2 第 4 次诚实未达标(G0/G1/G1-r/G1')。

**D5 触发**:B0 未能在存活与 recovery 上同时打赢 B3 → 按 ADR-0010 D5 + ADR-0003 升级 founder 定主张2 最终状态(对主张下结论是 founder 保留权)。机制结构修订权已尽,不再调机制;env 有效性权已用一次。
