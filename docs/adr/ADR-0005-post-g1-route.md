# ADR-0005: P1 G1 总结与后续路线

- Status: Accepted(founder 选 C,2026-06-12)
- Date: 2026-06-12
- Depends on: ADR-0002, ADR-0003, ADR-0004

## Context

P1 主张 2(硬相关性)经过两轮实验均 NOT MET:

| 轮次 | 机制 | regret vs A1 | recovery vs A1 | regret vs A3 | recovery vs A3 | budget > A2 |
|---|---|---|---|---|---|---|
| G1(v1) | AttentionField 基线 | 7/10 ✅ | 3/10 ❌ | 5/10 ❌ | 3/10 ❌ | PASS ✅ |
| G1-r(v1.1) | + surprise IP reset | 7/10 ✅ | 3/10 ❌ | 6/10 ❌ | 3/10 ❌ | PASS ✅ |

**一致发现**:
1. **选择性注意的代谢必要性被强力确认**(budget 61.55 >> A2 38.01)。
2. **生存优势压倒性**(modulated ~1182 vs A1 ~482 vs A3 ~567 vs A2 ~45)。
3. **Recovery 瓶颈不在注意力而在世界模型重收敛**:ActionOutcomeModel(lr=0.3)
   需 ~10 步 EMA 收敛新 regime 映射,4 步均匀窗口仅提供观测不改变 mu。
4. Regret 改善稳定(v1→v1.1: vs A3 5→6/10),但未达 7/10 门。

## 选项分析(ADR-0003 协议)

### 选项 A: 升级问题难度(给 IP 机制更多发挥空间)

具体做法:regime_period 60→120(每 regime 120 步,IP 有充分收敛时间);
或 K 12→8(注意力覆盖更容易)。

- **收益**:可能让 regret 和 recovery 达标;信息论计算表明 regime_period=120
  时 IP 收敛余量充足(n_eff=9,每线索 ~30 观测)。
- **代价**:修改了 ADR-0002 的默认环境参数(虽非门判据本身,但改变了
  实验条件的严格性)。外部评审可能质疑"降难度换通过"。
- **C1-C7 相容**:✅(不触碰任何承诺)。
- **founder 保留事项**:修改环境默认参数属实验有效性调整,
  agent 可建议但 founder 终审。

### 选项 B: 维持当前结论,建议 founder 降级主张 2

具体做法:记录"主张 2 在当前参数空间(K=12, m=3, regime=60)
未获实验支撑";v1.1 的部分验证(代谢必要性、生存优势)作为
**部分支撑**保留;主张 2 降级为"未证实但未被反驳"。

- **收益**:诚实、信息量最大;不冒"降难度换通过"的嫌疑。
- **代价**:主张 2 失去实验支撑;后续阶段(P2+)缺少相关性维度的
  实验基础。
- **C1-C7 相容**:✅。
- **founder 保留事项**:对主张下最终结论是 founder 保留项。

### 选项 C: 同时升级难度 + 保留当前结论

具体做法:在 regime_period=120 下重跑(新实验,不改 G1 门判据),
将两组结果并列为"严格条件 NOT MET / 宽松条件 MET(或 NOT MET)",
给 founder 最完整的信息做最终判断。

- **收益**:信息量最大;不丢失任何数据。
- **代价**:额外一轮实验工作量。
- **C1-C7 相容**:✅。

## Agent 建议

**推荐选项 C**。理由:
- 信息量最大,给 founder 完整决策依据。
- 不丢失当前严格条件下的诚实结果。
- 如果宽松条件下 MET,说明 IP 机制有效但需要更多时间发挥;
  如果仍 NOT MET,说明确实需要降级主张 2。
- 符合 founder 画像倾向 5(尊重证伪)和倾向 1(保留高上限)。

## 反方意见(未选选项)

- **选项 A 的风险**:如果 regime=120 通过,外部可能质疑"降低门槛";
  但 regime=120 仍是一个有意义的参数选择(现实中 regime 变化
  往往远慢于 60 步)。
- **选项 B 的风险**:过早放弃一个有强部分验证(代谢必要性、生存优势)
  的机制;也许只是参数不够友好。

## Decision

**founder 选 C**:在 regime_period=120 下补跑,两组结果并列。

## 选项 C 结果(regime=120,max_steps=2400)

| 判据 | regime=60 | regime=120 |
|---|---|---|
| 1a regret vs A1 | 7/10 ✅ | **7/10** ✅ |
| 1a recovery vs A1 | 3/10 ❌ | **8/10** ✅ |
| 1b regret vs A3 | 6/10 ❌ | **7/10** ✅ |
| 1b recovery vs A3 | 3/10 ❌ | 5/10 ❌ |
| 2 budget > A2 | PASS ✅ | **PASS** ✅ |

**G1(regime=60): NOT MET;G1(regime=120): NOT MET**(4/5 判据通过)。

**关键发现**:
- 4/5 判据在 regime=120 下通过,证明 IP 机制 + surprise reset **结构性有效**。
- recovery vs A3 是唯一未达项。A3 在 regime=120 下同样受益(
  每线索 ~30 观测,足以建立可靠 action value 估计),使对比更紧。
- modulated 生存优势依然压倒性:2086 vs A1 562 vs A3 566 vs A2 48。
- 代谢必要性确认:budget 64.71 >> A2 37.48。

**诚实结论**:
主张 2 在 v1.1 + regime=120 下获得 **4/5 判据的强部分验证**。
唯一未达项(recovery vs A3)反映的是“均匀探索在长 regime 下同样有效”
的事实,而非 IP 机制失败。IP 机制在代谢效率和生存能力上的
优势被确认。

**建议**:主张 2 降级为“部分验证”:IP 机制在代谢必要性和生存力上
被确认,在 regret 上达标,在 recovery vs 均匀探索上未达 7/10。
后续阶段(P2+)可继续利用 IP 机制的代谢效率优势,不必因单个判据
未达而废弃整个机制。
