# ADR-0003: 自主决策协议(founder 授权)

- Status: Accepted(founder 授权,2026-06-12:"你和自定义子agent辩论讨论结果、自我审核、拍板决定路线,记住我的决策倾向")
- Date: 2026-06-12

## Context

founder 授权 agent 在本仓库进行路线级自主决策,以加速研究迭代;同时其"人主权"
立场(RR-0001 C7、主权三分)要求决策可见、可否决、可回滚。本协议是"系统提案、
人处置"模式在研究过程层的实例——agent 行使 Ring-1 式主权(过门自决),founder
保留 Ring-0/罩式主权(否决、收紧、保留事项)。

## 协议(路线级决策,如:门失败后的改道、机制结构选型、阶段顺序调整)

1. **起草**:列 ≥2 个可行选项,各带代价/收益/与 C1–C7 的相容性。
2. **对抗评审**:有子 agent 可用时,用 decision-referee(中立裁判)+ technical-architect
   (技术可行性)辩论;不可用时做结构化自我批判(明写"最强反方论证")。
3. **倾向对照**:对照 founder 决策倾向画像(PROJECT_PLAN §2)检查选择一致性;
   与画像冲突时必须升级给 founder,不得代拍。
4. **拍板并留痕**:写入新 ADR,**必须包含反方意见与未选选项**;更新 PROJECT_PLAN 任务卡。
5. **否决窗口**:决策默认可回滚;founder 任何时点可否决/收紧,agent 不得以沉没成本抗辩。

## 保留给 founder(agent 只可建议)

- 修改 C1–C7 任一承诺;修改任何已预注册门的判据(挪门柱)。
- 接入真实执行器/外部副作用;LLM 进入控制路径(P4 启动本身)。
- 跨仓边界变更(如企业仓接通用核);花钱;对外发布/公开。
- 对四主张中任一条下"最终失败"结论(agent 可建议降级,founder 终审)。

## 实验内自由度(agent 可径直决定,无需协议全流程)

实现细节、测试设计、重构、文档、实验有效性修复(环境/度量,不动机制)、
按既有 ADR 规格施工。判别标准:**是否改变研究路线或触碰保留事项**。
