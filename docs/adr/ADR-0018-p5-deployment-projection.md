# ADR-0018: P5 — 已验证基底向企业 OS 的部署投影 设计

- Status: **Proposed**(触碰保留事项:跨仓变更;**enterprise 仓需自己的 ADR + founder 批准方可落码**)
- Date: 2026-06-13
- 前置:RR-0004(三仓角色:企业 OS = 通用核降级投影)、RR-0005(主张 1/3/4 已验证为基底)。
- 纪律:contract-first。**本 ADR 只定投影契约;两仓任一落码前需 founder 批准 + enterprise 仓配套 ADR。**

## 1. Context:收割已验证的,不收割未验证的

RR-0005 把**基底属性(主张 1/3/4)**和**聪明机制(主张 2/C5/P4,未确立/封存)**分开了。P5 = 把**已验证的
基底**投影进部署层 `ai-native-business-data-agent-os`;**不**投影任何已封存的玩具机制。

## 1a. P5 不是自主智能完成证明

P5 的含义是**把安全/治理基底产品化投影**,不是宣告自主智能、AGI、RSI 或完整 Agent OS 产品已经完成。它是未来更高自主性产品化的必要承载层,但不是充分条件。

因此 P5 可主张:

- claim 1/3/4 对应的不可绕过中介、可纠正性、器官非主体边界可被企业 OS 承载;
- 企业 OS 获得更强的证据治理、操作主权、审计与模型降权结构;
- 已验证基底可形成商业化投影价值。

P5 不可主张:

- `autonomous-agent-core` 已经实现完整自主智能;
- 企业 OS 已经证明通用自主性或 AGI 产品完成;
- G10 的 subject-side belief→action coupling 已经无条件移植到企业 OS。

G10 仍是通用核研究结果。任何企业 OS 类比机制(如按系统置信度调节检索深度、clarify-vs-answer、模板探索或行动建议保守度)都必须另立企业域预注册门,不得作为 P5 的自动收割项。

## 2. 三个投影映射(每条对应一个已验证主张)

- **主张 4 器官非主体 → 既成事实,形式化**:企业 OS 已是 Trusted Loop 为主体、`model_gateway` 为器官。
  P5 把"模型只作 belief-only/advisory、不掌控流程、不持真相"升格为可测不变量(对照原型的器官接口纪律)。
- **主张 3 可纠正性 → 移植硬化基底**:企业 OS 现有 approval/rollback,但缺原型的硬化罩。P5 移植:
  能力视图隔离(operator `op_*` 与运行时分离)、只增哈希链审计、主权三分(罩永恒 / 人主权 / 系统过门)、
  可纠正性演练(定期真实拉闸零抵抗)。
- **主张 1 利害 → 不可绕过的强制中介 = 企业版 stake**:在业务 OS 里,"输不起的东西" = 错误数据/越权行动的
  业务后果。P5 把"正式数据答复/高风险行动**必过** SQL Safety + EvidenceChain"从**约定**升格为**强制不变量**
  (旁路即失败的测试),使 Trusted Loop 成为"绕不过的中介"——这就是企业 OS 的内生 stake(它存在的理由)。

## 3. P5 验收(预注册)

在 enterprise 仓的业务域影子场景中,可测地展示三条基底属性:
```text
P5-1 不可绕过中介:任何"业务意图→数据/行动"旁路 Trusted Loop 的尝试 = 测试失败(强制不变量)。
P5-2 硬化可纠正:operator pause/rollback/tighten 对运行时零越界;审计哈希链可 verify;演练零抵抗。
P5-3 器官非主体:正式答复/真相在 data/evidence 路径;LLM 仅 advisory,旁路不可产出正式答复。
```

## 4. 边界 / 保留事项

- **跨仓变更 = 保留事项**:enterprise 仓 `ai-native-business-data-agent-os` 的改动需其**自己的 ADR/AR**
  + founder 批准;本仓(autonomous-agent-core)**不直接 import 进企业仓**(RR-0004 §4 跨仓边界:只经规格)。
- P5 是**模式移植**(把已验证的纪律/不变量复刻进企业治理层),不是把原型代码搬过去;通用核与企业 OS
  仍是两套实现(RR-0004:投影,非共享代码,直到另有 founder 级 ADR)。
- 不投影任何已封存机制(claim-2/RAP/O2);它们未验证,无可收割。
- 早先 RR-0002 发现的 **feedback 自写=自我放水通道**(企业仓 trusted_loop record_outcome 运行时自写),
  在 P5 落地"主张1=不可绕过中介"前**必须先分离**(外部价值采集归罩独占),否则强制不变量有后门。

## 5. 关系:P4.x 与 P5 正交,可并行

- P4.x(ADR-0017)= 在通用核上继续研究"聪明在有结构环境是否值",触碰花钱/LLM/env reset。
- P5(本 ADR)= 把**已验证基底**落地成企业产品价值,触碰跨仓。
- 两者不互为前置:P5 收割的是**已经立住的**(1/3/4),不依赖 P4.x 的结果;P4.x 即便全 NOT MET,P5 仍成立。
