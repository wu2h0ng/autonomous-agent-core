# ADR-0001 Addendum: P5.1b Current Semantics

- Status: Accepted implementation addendum (2026-06-14)
- Parent: `ADR-0001-p5-substrate-harvest.md`
- Architecture review: `docs/architecture_reviews/AR-20260614-p5.1b-adoption-driven-knowledge.md`

## Decision

P5.1b closes the remaining self-report knowledge-promotion path:

- `TrustedLoopRuntime.record_outcome()` records runtime self-report feedback as an observation only.
- Self-report feedback does **not** supersede or version a `KnowledgeAsset`.
- `TrustedLoopRuntime.promote_from_adoption(trace_id)` is the only runtime knowledge-promotion path in this slice.
- Promotion reads realized external value through the injected read-only `AdoptionLedgerView`.
- The runtime still holds no `AdoptionIngest` writer; the operator/composition layer holds the writer.
- The HTTP operator surface is `POST /adoptions`; `POST /outcomes` remains self-report only.

This supersedes older Stage-1 wording that described `record_outcome()` as folding feedback directly into knowledge. Historical baseline documents under `docs/project_baseline/` are archival imports and are not current product contracts.
