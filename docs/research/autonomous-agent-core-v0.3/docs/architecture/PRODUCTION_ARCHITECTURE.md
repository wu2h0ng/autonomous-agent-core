# Production Architecture

Layers:

1. Experience Layer
   - Web UI
   - API clients

2. Agent Platform Layer
   - Agent orchestration
   - Goal compiler
   - Planner
   - Memory manager

3. Cognitive Layer
   - LLM adapter
   - CWM adapter
   - Causal reasoning adapter

4. Governance Layer
   - Ontology
   - Policy
   - Arbiter
   - Audit

5. Runtime Layer
   - Tool execution
   - Sandbox
   - Permissions

6. Infrastructure Layer
   - Kubernetes
   - Databases
   - Event streaming
