## Non-Delegable Gates

- CTO owns architecture, implementation authenticity, security-sensitive engineering gates.
- CEO owns company-level customer, capital, roadmap, and business authorization.
- Security/Legal/Finance gates cannot be bypassed by CEO/CTO/Product/PM.
