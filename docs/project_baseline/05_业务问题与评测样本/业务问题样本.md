# AI Native Business Data OS — 高频业务问题清单

> 目标：覆盖 30 个真实业务场景的自然语言问题，用于 Agent 测试验证和推荐问题展示。

---

## 一、ROI 与投放效率（Questions 1-8）

| # | 问题 | 期望能力 |
|---|---|---|
| 1 | 今天的 ROI 趋势如何？和昨天对比有什么变化？ | Schema 识别 → SQL 查询 → 趋势分析 |
| 2 | 小红书和抖音的 ROI 哪个更高？近 7 天趋势 | 跨平台对比，多 schema 查询 |
| 3 | 千川投放的 ROI 最近 3 天为什么在下降？ | 归因分析，关联爆款内容/竞品数据 |
| 4 | 哪个投放计划的 ROI 最低？建议怎么优化？ | 排序 + 低效计划识别 + 优化建议 |
| 5 | GMV 环比增长率是多少？按平台拆解 | 环比计算，多维度下钻 |
| 6 | 本月广告花费最多的 5 个计划，转化率分别是多少？ | Top-N 排序，复合指标查询 |
| 7 | 哪些素材（视频/图片）的点击率最高？ | 素材维度分析，TOP 排行 |
| 8 | 聚光投放和千川投放的 CAC（获客成本）对比 | 跨平台指标对比 |
